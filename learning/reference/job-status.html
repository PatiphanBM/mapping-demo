File job (file_jobs)

importStatus

Queued→ Delaying→ Importing→ Importedหรือ ImportFailedหรือ Duplicate
สถานะใครตั้งเมื่อไร
QueuedFileIntake (API)Watcher เจอไฟล์และสร้างงาน หรือมีคนสั่ง Retry งานที่ ImportFailed
DelayingFileImportHandlerหยิบงานแล้ว กำลังรอตาม Import:DelaySeconds
ImportingFileImportHandlerกำลังอ่านไฟล์ลง Source ทีละแถว
ImportedFileImportHandlerอ่านครบทุกแถว ได้ totalRows
ImportFailedFileImportHandlerheader ไม่ครบหรือเกิด exception ระหว่าง import ดูสาเหตุที่ lastError
DuplicateFileImportHandlerเนื้อหา (SHA-256) ซ้ำกับไฟล์ที่รับไว้แล้วภายใต้ config เดียวกัน

archiveStatus

NotArchived→ Archivedหรือ ArchiveFailedหรือ ChangedAfterRead

Import worker ย้ายไฟล์ไป archive/<ddMMyyyy>/ ทันทีหลัง import จบ ไม่รอ normalize

normalizationStatus (คำนวณตอนถาม ไม่ได้เก็บในตาราง)

InProgress→ Completedหรือ CompletedWithErrors
เงื่อนไข (ตามลำดับ)ผล
importStatus ไม่ใช่ Imported หรือ pendingRows > 0InProgress
invalidRows > 0 หรือ failedRows > 0CompletedWithErrors
นอกนั้นCompleted

ที่มา: src/MappingDemo.Shared/Jobs/NormalizationStatusCalculator.cs ตัวนับใช้ row job ล่าสุดของแต่ละแถว

Row job (row_jobs)

Pending→ Doneหรือ Invalidหรือ Failed
สถานะความหมาย
Pendingบันทึก Source แล้ว รอ Normalize worker
Doneผ่านกฎทุกข้อ บันทึกลง Normalized Table แล้ว
Invalidข้อมูลไม่ผ่านกฎ normalize รายละเอียดอยู่ใน Row Error
Failedเกิด exception ครบ 4 รอบ (ลองใหม่หลัง 1, 2, 4 วินาที) ดูสาเหตุที่ lastError

handler ข้าม message ของ row job ที่อยู่ในสถานะสุดท้ายแล้ว จึงรับ message ซ้ำได้โดยไม่เกิดผลซ้ำ

Endpoint สำหรับดูสถานะ

Endpointได้อะไร
GET /file-jobsทุกงาน เรียงจากใหม่ไปเก่า
GET /file-jobs/{id}สถานะสามแกน, totalRows, ตัวนับ pending/done/invalid/failed, lastError, createdAt, updatedAt
GET /file-jobs/{id}/errorsRow Error ทุกแถว (เลขแถว, field, สาเหตุ)
GET /file-jobs/{id}/rows/{rowNumber}/historyประวัติ row job ทุกรอบของแถวนั้น รวม retry และ reprocess
