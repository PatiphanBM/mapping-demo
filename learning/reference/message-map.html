ค่า config ของ Kafka client

ค่าที่ความหมายสั้น ๆ
BootstrapServers = localhost:9092appsettingsที่อยู่ Kafka จากเครื่อง host (ใน Docker ใช้ kafka:19092)
Acks = All, EnableIdempotence = trueWorker Program.cs (producer)ให้ Kafka ยืนยันว่าเก็บ message แล้วจริงและไม่บันทึกซ้ำ (เชิงลึก)
EnableAutoCommit = falseconsumer ทั้งสองแจ้ง Kafka ว่าทำเสร็จ หลัง handler ทำงานจบเท่านั้น
AutoOffsetReset = Earliestconsumer ทั้งสองworker กลุ่มใหม่เริ่มอ่านจาก message แรกสุดใน topic

ดูของจริงได้ที่ไหน

  • Kafka UI localhost:8080 → Topics → ชื่อ topic → Messages
  • outbox ที่ยังไม่ส่ง: 
    docker compose exec postgres psql -U mapping -d mapping -c "SELECT id, topic, message_key, created_at, sent_at FROM outbox WHERE sent_at IS NULL ORDER BY id;"
  • log ของ Worker: Dispatched outbox message … (ส่งแล้ว) และ Consumer N consumed …, partition P, offset O, key K (อ่านแล้ว)
