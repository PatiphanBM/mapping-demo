# จุดเริ่มต้น: สร้างระบบแล้ว แต่ยังไม่เข้าใจ queue/worker/Kafka

ผู้เรียนบอกเองว่า "ไม่ค่อยมีความเข้าใจเกี่ยวกับ queue, worker และ Kafka" ทั้งที่ learning plan ของ mapping-demo ติ๊ก Phase 7–9 (Outbox, File Watcher, Outbox Dispatcher) และ 15–17 ไปแล้ว แปลว่าโค้ดส่วน messaging มีอยู่จริงแต่ผู้เรียนยังมองเป็นกล่องดำ

**Implications**: เริ่มจากแนวคิดพื้นฐาน (ทำไมต้องแยกงานผ่าน queue) ไม่ใช่ API ของ Confluent.Kafka และใช้โค้ดที่มีอยู่แล้วเป็นตัวอย่างทุกครั้ง เพราะผู้เรียนคุ้นกับชื่อไฟล์/คลาสอยู่แล้ว
